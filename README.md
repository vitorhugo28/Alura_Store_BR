# 📊 Challenge Data Science - Análise de Performance de Retalho

Este projeto foca na análise técnica de dados de quatro unidades de uma rede de retalho (AluraStore), utilizando Python e Pandas para suporte à decisão estratégica.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** Python 3.10
* **Bibliotecas:** Pandas (Tratamento), Matplotlib/Seaborn (Visualização).
* **Ambiente:** Google Colab.

## 📈 Etapas do Projeto
1. **ETL (Extract, Transform, Load):** Importação automatizada de múltiplos ficheiros CSV via URL.
2. **Data Cleaning:** Verificação de dados nulos e integridade das colunas.
3. **Análise Estatística:** Cálculo de faturamento total, ticket médio de frete e rankings de produtos/categorias.
4. **Insights de Negócio:** Cruzamento de métricas de logística vs. satisfação do cliente.

## 💡 Principais Descobertas
* O faturamento total da rede ultrapassa os **R$ 5,8 milhões**.
* Existe uma correlação negativa entre o custo do frete e a avaliação da loja.
* A recomendação final foi o desinvestimento na **Loja 4** devido ao baixo faturamento e baixo potencial de crescimento local.

## 📂 Como visualizar
O notebook principal contém toda a lógica de programação, desde a criação dos dicionários de dados até a geração dos gráficos de faturamento e participação de mercado.
